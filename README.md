# Credit Card Fraud Detection
## Project Overview
This project uses Machine Learning to detect fraudulent credit card transactions. It analyzes transaction data and trains classification models to identify potentially fraudulent activities.
## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Google Colab / Jupyter Notebook
## Project Files
- `Credit_Card_Fraud_Detection.ipynb` — Notebook containing data preprocessing, model training, evaluation, and tuning.
- `fraud_detection_results.csv` — CSV file containing model evaluation results.
- `README.md` 
## How to Run the Project
1. Download or clone this repository.
2. Open [Google Colab](https://colab.research.google.com/) or Jupyter Notebook.
3. Upload and open the project notebook.
4. Upload the credit card fraud detection dataset when prompted, or update the dataset file path in the notebook.
5. Run all cells in order to preprocess the data, train the models, and evaluate their performance.
6. The results CSV file can be downloaded after running the notebook's export cell.
## Project Objectives
- Preprocess transaction data.
- Train and compare machine learning models.
- Evaluate model performance using precision, recall, and other classification metrics.
- Tune a Random Forest model to improve performance.
## Dataset
The project uses a credit card transaction dataset containing legitimate and fraudulent transactions.
## Dataset Source
MLG-ULB. Credit Card Fraud Detection dataset. Kaggle. https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
